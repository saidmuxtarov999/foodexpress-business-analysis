# Contributing Guide

Thank you for contributing to the FoodExpress Business Analysis project.

## Workflow

1. Create a feature branch.
2. Implement the required changes.
3. Commit using meaningful commit messages.
4. Open a Pull Request.
5. Request review.
6. Merge after approval.

## Branch Naming

feature/...
bugfix/...
hotfix/...

## Commit Messages

Examples:

- Add authentication API documentation
- Update ERD
- Fix acceptance criteria

## Pull Requests

Every Pull Request should reference the related GitHub Issue.
