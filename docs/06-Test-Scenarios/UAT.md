# User Acceptance Test Scenarios

| ID | Scenario | Expected Result |
|----|----------|-----------------|
| UAT-01 | Customer registers a new account | Registration completed successfully |
| UAT-02 | Customer logs into the system | User is authenticated |
| UAT-03 | Customer searches for restaurants | Matching restaurants are displayed |
| UAT-04 | Customer adds items to cart | Cart is updated correctly |
| UAT-05 | Customer places an order | Order is successfully created |
| UAT-06 | Customer completes online payment | Payment is successful |
| UAT-07 | Restaurant accepts an order | Order status changes to Accepted |
| UAT-08 | Courier accepts delivery | Courier is assigned |
| UAT-09 | Customer tracks order | Current order status is displayed |
| UAT-10 | Admin views dashboard reports | Reports are displayed correctly |
