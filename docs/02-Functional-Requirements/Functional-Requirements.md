# Functional Requirements

This document contains all functional requirements of the FoodExpress platform.

| FR ID | Functional Requirement | Related BR |
|-------|-------------------------|------------|
| FR-01 | Sistem müştərinin sifariş yaratmasına imkan verməlidir | BR-01 |
| FR-02 | Sistem sifariş statuslarını avtomatik yeniləməlidir | BR-01 |
| FR-03 | Sistem restoran axtarışı və filtrləmə funksiyası təqdim etməlidir | BR-02 |
| FR-04 | Sistem səbət (cart) idarəetməsini təmin etməlidir | BR-02 |
| FR-05 | Restoran sifarişi qəbul və ya imtina edə bilməlidir | BR-03 |

| FR-07 | Sistem kuryer təyinatını avtomatik həyata keçirməlidir | BR-04 |
| FR-08 | Sistem marşrut optimallaşdırmasını təmin etməlidir | BR-04 |
| FR-09 | Sistem sifarişin real-time izlənməsini təmin etməlidir | BR-05 |
| FR-10 | Admin panel sifariş və gəlir hesabatlarını göstərməlidir | BR-06 |
| FR-11 | Sistem push bildirişlər göndərməlidir | BR-07 |
